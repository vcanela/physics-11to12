# Year 11 Physics Catch-Up

Self-paced pages for a student starting NCEA Level 2 Physics without having taken Year 11 physics. Built for one-to-one tutoring, and free for any teacher or tutor to use.

**Live site:** https://vcanela.github.io/physics-11to12/

## Topics

1. Maths toolkit: units, scientific notation, significant figures, rearranging, gradient and area, trigonometry
2. Mechanics: motion, graphs, forces, pressure, energy, work and power
3. Electricity and magnetism: charge, circuits, power, magnetic fields
4. Waves and light: wave properties, sound, reflection, refraction
5. Writing explanations: what lifts an answer from Achieved to Merit to Excellence
6. Graphs and investigations: planning, data, hand graphing, linearising curves

Each topic ends with a "What comes next" section previewing Level 2.

## How the pages work

- Key ideas, then worked examples, then questions.
- Calculation questions show **only the final number** behind a button. The working is checked in person with the tutor.
- Explain, sketch and discuss questions have **no answers** on the pages. Students bring their attempts to sessions.
- There is no marking or self-assessment anywhere. Initial diagnostics happen in person.
- Interactive explorers (motion stories, series and parallel circuits, waves, linearising data) are for exploring, not testing.
- Every page prints cleanly, with space left for working.

## Technical

Plain HTML, CSS and JavaScript: one self-contained file per page, with no build step and no dependencies beyond IBM Plex fonts from Google Fonts. Served by GitHub Pages from `main`.
